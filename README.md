# Shreya — Product-company data interview curriculum (Fresher)

This is a self-study curriculum for entry-level Data Analyst, Product Analyst, BI Analyst and Junior Data Engineer roles. It is designed to teach concepts progressively, with distinct exercises, worked solutions, concept checks and timed mock tests.

## Start here
Read `modules/00_START_HERE_AND_STUDY_METHOD.md` first. Follow the 20-week route and attempt exercises before reading solutions.

## Modules
1. Relational foundations and SQL beginner
2. SQL joins, aggregation and intermediate queries
3. Advanced SQL: windows, dates and tuning
4. DBMS, design, transactions and performance
5. Python fundamentals and problem solving
6. Python data handling, pandas and testing
7. Statistics and product analytics
8. Excel, Power BI and dashboards
9. Data modelling, warehousing and ETL
10. Data engineering systems, cloud and Spark
11. Project defence and resume lab
12. Role-specific fresher mock interviews

## Assessments
`mock_tests/` contains separate SQL and Python concept checks/final tests. Each module also has its own exercises, solutions and mini assessment. The role-specific mocks are in Module 12.

## Important study rule
Do not memorise the solution. Re-solve it with changed input. Explain the row grain, assumptions, edge cases and complexity. Keep an error log and reattempt missed questions after 1, 3 and 7 days.

## Project facts to preserve
- RetailPulse: profitability should not be described as validated until source cost-field mapping is verified.
- WeatherScope: forecasts are predictions, not observed weather or official warnings; the 50% rain-risk threshold is project-defined.
- TrustLayer: synthetic test data is not real NYC statistics; a single extract with no rejects does not prove the source is universally clean; no dashboard/scheduler is claimed unless implemented.

## Not a hiring guarantee
Interview formats vary by company and job description. These are original practice materials, not leaked or guaranteed questions. Some companies add DSA, aptitude, take-home assignments or tool-specific rounds.


## External practice is embedded in every module
Each module ends with a topic-specific External Practice section. It maps the concepts taught in that module to relevant LeetCode, HackerRank, SQLBolt, PostgreSQL Exercises, DataLemur, StrataScratch, Kaggle, Microsoft Learn, official documentation and other suitable resources. It also states what to complete and the exit requirement. These links are intentionally placed beside the relevant lesson, not collected only in a separate resource appendix.
