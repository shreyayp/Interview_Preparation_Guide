A structured, self-study curriculum for entry-level **Data Analyst, Product Analyst, BI Analyst and Junior Data Engineer** roles.

Use this page as the main table of contents. Follow the learning sequence below, attempt exercises before reading solutions, complete the practice links inside each module, and use the mock tests to check readiness.

## Suggested study workflow

1. Read the concept explanation in the Markdown module or its PDF.
2. Work through the guided examples.
3. Attempt every independent exercise before checking its solution.
4. Complete the external practice links listed inside that module.
5. Record mistakes and revisit the relevant concept.
6. Complete the subject concept check.
7. Practise the timed role-specific mocks in Module 12.
8. Prepare to explain the three portfolio projects using the project documentation and Module 11.

## Role-based focus

- **Data Analyst / BI Analyst:** Prioritise SQL (Modules 01–04), Python and pandas (Modules 05–06), statistics (Module 07), and Excel/Power BI (Module 08).
- **Product Analyst:** Prioritise SQL (Modules 01–04), statistics and experimentation (Module 07), and project/business reasoning (Modules 11–12).
- **Junior Data Engineer:** Complete SQL and DBMS (Modules 01–04), Python and testing (Modules 05–06), data modelling and ETL (Module 09), and systems/cloud/Spark (Module 10).
